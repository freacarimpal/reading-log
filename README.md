# 📚 My Reading Log

> *"One more chapter..."*

A simple web application to track the books I am reading, monitor my reading progress, and manage due dates for borrowed books.

### ✨ Live Demo
👉 https://freacarimpal.github.io/reading-log/

### 🚀 Features
- 📖 Add Books - Add title, author, and total pages
- 📊 Track Progress - See your reading percentage
- 📅 Due Date Reminder - Avoid library penalties
- 💾 Auto-Save - Your data is saved automatically
- 📱 Mobile Friendly - Works on phone, tablet, and laptop

### 🛠️ Built With
HTML | CSS | JavaScript
